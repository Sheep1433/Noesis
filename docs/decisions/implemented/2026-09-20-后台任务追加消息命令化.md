# 决策：后台任务追加消息命令化（多实例写面补全）

状态：implemented
日期：2026-09-20

## 问题

`bg-task-durable-facts` 落地后查询面任意实例可答、停止已命令化，但追加消息的执行仍隐式绑定 leader 进程：执行器实例只在 leader 装配，`/subagent-messages` 落到 follower 抛 RuntimeError（500）；且受理先写 pending 行、异常清理只捕 `ValueError`——每次失败的追加都留下一行永无消费者的孤儿 pending 行，占死容量配额（10 条后该任务追加通道整体堵死）。openspec `bg-task-message-command` 承载收口。

## 决策

### 1. 命令即引用：`bg_task_deliver` 只带 `(child_session_id, message_id)`

write-ahead 改造后 pending 行本身就在 PG——命令不需要携带内容，行就是队列事实与载荷的合一。pending 行与命令行**同一事务**写入，孤儿行结构上不可能（命令写失败则行不存在）。被否：命令携带消息内容（双写制造权威问题）。

### 2. 单一路径：模型工具与用户 HTTP 同走命令表，不设 leader 本地直通

表面上 leader 给自己发命令绕路，实际 wakeup 即时唤醒（毫秒级）无感知延迟；收益是受理与消费各只有一份代码——本地直通会在两处入口各留一份容量/校验/翻转逻辑，且换主后旧 leader 的「本地直通」会在非 leader 上执行任务，破坏单 leader 执行不变量。

### 3. 不引入 LeadershipPort：受理端无需感知领导权

原设想受理端判据「我是不是 leader」；核对消费者实现后修正——`claim_pending` 前置 token 有效性校验（follower 天然不认领），wakeup 订阅使角色无关。删除判据即删除「换主后旧 leader 误判」整类风险。

### 4. 消费四分派 + 已取消任务分流：停止不被遗留消息覆写

消费按目标任务状态分派：行已非 pending → 空转（幂等）；任务非终态但热集 miss（换主窗口）→ 空转延后（不得翻转行——排队任务的指示随重建保留）；不可续 → 翻转 dropped + 命令 rejected；可续 → 执行。cancelled 附加分流：**受理先于取消**的消息 no_op 保留 pending（不被动复活任务，避免静默代执行越权），**受理晚于取消**的（用户主动追问）正常冷恢复。

### 5. 认领租约：claimed 命令崩溃回收

`claim_pending` 是持久事实（status 固化），leader 在认领与终态标记之间崩溃会让命令永久卡 claimed。补扫重置超租约（30s）的 claimed 行回 pending，晋升对账重置全部遗留 claimed 行；幂等由消费端行状态 + 镜像队列按 message_id 查重承担，重放安全。连带修正：执行镜像 deque 取消 maxlen——满后 append 静默淘汰的条目对应行仍 pending，恰是滞留形态；容量执法完全上移受理端。

### 6. 命名零残留：followup 词汇退出代码

`grep -ri followup`（backend/packages、backend/server、backend/tests、frontend/src、frontend/__tests__）零命中为验收门槛：`_arun_followup` → `_arun_appended_turn`、`FollowupQueue/` → `MessageQueue/`、`queuedFollowups.ts` → `queuedMessages.ts`、`SubagentFollowupRequest` → `SubagentMessageRequest`、事件名 `"followup"` → `"message-appended"` 等约 30 组符号。不做旧名别名或转发层。

## 备选方案

- **命令携带消息内容**：双写制造权威问题，引用化免费获得幂等校验落点。
- **leader 本地直通（工具路径不走命令）**：双入口逻辑漂移 + 换主误执行，见决策 2。
- **LeadershipPort 感知领导权**：消费者 token 校验已覆盖，判据本身是风险面，见决策 3。
- **Redis 直发执行信号**：at-most-once 丢失后仍需补扫轮询，等价于命令表却多一条不可靠路径。
- **受理端捕所有异常清理孤儿行**：只治标（仍 500），且「写行再清理」窗口内行已对外可见；事务化让孤儿不可能存在。

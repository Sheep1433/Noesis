# 决策：记忆检索三层修复——grep 候选集、search 排序与摘录化

状态：implemented
日期：2026-09-09

## 问题

记忆评测基线（`baseline-2026-09-v2`，答案正确率 47.4%）的失败归因暴露出
检索模块三层缺陷，逐层实测确认：

1. **`/memory` 的 grep 搜不到条目正文**（bug）：`GuardedFilesystemBackend.grep`
   的候选文件集写死为根文件（MEMORY.md/AGENTS.md/USER.md）+ journal，五类
   类型目录下的记忆条目永不在候选集；以目录为 path 调用也不展开。实测：
   条目正文含关键词，grep 只命中 MEMORY.md 索引行——返回误导性的稀薄结果
   而非干净报错，agent 被带去逐文件 read_file（read_file 另有 20K 输出
   截断，条目上限 50K 需翻页），进而委派后台子 Agent 扫 47 个文件、回合
   空转直至失败（评测样本 7024f17c 的完整失败链）。
2. **`MemoryStore.search` 无相关性排序**：命中集按字母序 glob 取前 limit 个，
   与查询相关度无关；相关条目字母序靠后就被挤掉（基线 precision@k 仅 0.40
   的直接原因）。docstring 声称「索引行 + journal 命中」，实现只扫类型目录，
   journal 经 search_memory 不可达。
3. **命中项返回全文**：`content` 字段带完整正文（单条目上限 50K 字符 ×
   limit=5 直塞工具结果），基线实测单样本平均 20 万 input token 的主要来源，
   上下文膨胀挤压推理质量。

## 决策

- **grep 候选集按路径展开**：`/` → 根文件 + journal + 五类目录全部条目；
  `/<type>` 或 `/journal` → 该目录条目（scoped 检索不掺根文件）；具体文件
  → 该文件。逐行匹配与 50 条上限语义不变。
- **search 行级匹配（grep 语义）**：返回命中行的路径、行号与内容
  （{memory_type, slug, rel_path, line, content}），上限 50 行；同行命中
  越多越靠前（grep 多模式匹配的自然语义）。journal 纳入扫描范围（未限定
  memory_type 时）。相关性判断交给模型——看行内容决定哪个文件值得
  read_file（可带 offset 定点读）。
- **演进记录**：第一版做过「条目级命中数排序 + 摘录窗口」，评测实测暴露
  缺陷——通用词查询下命中数排序奖励长闲聊文件而非相关文件（查询 11 次
  换词，第 2-10 名永远是同一批关键词汤），摘录窗口也可能不含答案细节。
  行级匹配让证据本身可见，模型自行决策，工具不再替模型猜相关性。
  frontmatter 行（label/description 关键词密度高，会常年霸榜）不参与
  匹配——元数据导航由 MEMORY.md 索引承载。

## 备选方案

- **search_memory 改语义检索（pg_trgm/embedding）**：否——记忆条目是文件
  层资产，字面匹配保证「写进去就能搜到」的可解释契约；语义层召回已有
  search_sessions（t_chat_message 的 pg_trgm）承担，两层分工不变。
- **read_file 输出上限从 20K 提到 50K**：否——治标；摘录 + grep 定位后
  agent 只需按 offset 读需要的段落，不需要整条倾倒。
- **grep 返回干净报错「不支持」而非稀薄结果**：被展开候选集取代——条目
  本来就应该可搜，报错是把能力做没了。

## 代价

- 依赖 `content` 全文的调用方需改走 read_file：全仓检索确认消费方只有
  模型（工具渲染），评测只用 slug/rel_path，无迁移面。
- grep 全量扫描条目的单次成本上升（条目数 × 全文读）；上限 50 命中 +
  每文件 100K 读限与原实现一致，个人记忆规模（百级条目）下可接受。

## 验证

- `tests/test_user_memory_backend.py` 新增 grep 条目命中/目录 scoped/journal
  命中；`tests/test_memory_file_layer.py` 新增行级命中契约、同行多词优先、
  journal 可检索。记忆全量测试 86 passed，改动文件 ruff 干净。
- 工具层实测：search_memory 返回行级命中（含行号与行内容），frontmatter
  行不参与匹配。
- 评测回归：grep 失败链样本（7024f17c）复跑验证修复后行为。

# 决策：模型解析不回退——显式选择的 id 不可解析即报错

状态：implemented
日期：2026-09-03

## 问题

用户显式选择的模型 id（请求携带 / 会话 extra / 用户偏好）在解析失败时被多层静默回退吞掉，最终落到平台默认模型。「用户配了 A 实际跑 B」无声发生：2026-09-03 演示会话（子 Agent 走 kilo 而非配置的 token/glm-5.3-flash）、同日接口测试轮（主 run 全部 kilo，因偏好无消费者）均为实证。用户裁决：「不要回退方案，模型请求不通就应该报错——用户什么配置发的请求，直接去调用，模型厂商自己会返回对应的报错。」

静默回退的三个病灶：

1. `_resolve_model_for_query` 的每个选择点（请求/会话 extra/偏好）未命中自定义快照后调宽松 `resolve_catalog_entry`，未知 id 兜底平台默认。
2. `get_llm(model_id=...)` 的目录分支同样宽松兜底——ContextVar 快照在隔离线程丢失时（子 Agent），复合 id 在此静默变成平台默认。
3. 子 Agent 隔离线程不继承 `ContextVar`，自定义模型快照根本不可见——即使 1、2 修掉也只是「大声报错」而非「正确路由」。

## 决策

- **strict 解析**：新增 `resolve_catalog_entry_strict`——快照命中、内置目录命中之外的一切取值抛 `NotFoundException("模型不存在或已失效: id")`。`_resolve_model_for_query` 三个选择点与 `get_llm` 的显式 model_id 分支全部换用 strict。
- **「无任何选择」仍走平台默认**：请求、会话、偏好均未指定时用 `get_default_model_id()`，这是默认值语义而非回退，保留。
- **跨线程重放**：新增 `replay_runtime_model_snapshot(snapshot, target_model_id)`。父 run 构建子 Agent 工厂时捕获已解析的快照（纯 dataclass，跨线程安全），worker 在隔离 loop 开局重放进本线程 ContextVar。快照 id 与目标 model_id 不一致（followup 按 turn 覆盖到别的模型）时不重放——让解析 strict 报错，绝不用错模型。
- 宽松 `resolve_catalog_entry` 保留给展示/兜底场景（`_resolved_model_name` 等不涉及「实际调用哪个模型」的路径）。

## 备选方案

- **保留回退但加告警日志**：被否——日志无人盯，演示事故已经证明「无声漂移」会直接到用户面前；且回退终点（平台默认 kilo 免费池）与用户所选模型的能力差异会造成拒答/限流等二次故障，归因困难。
- **隔离线程内按 model_id 重新查库解析**：被否——隔离 loop 访问 DB 必须 `run_on_main_loop`（跨 loop 连接报错，既有教训），在 worker 开局做异步解析会拖长启动链并引入新的跨 loop 时序；主侧捕获纯数据快照重放是零 IO 的。
- **把 model_id 显式传参贯穿到每次 LLM 调用、彻底废除 ContextVar**：方向正确但波及 get_llm 全部调用方（同步函数无法查库解析快照），需要先把快照解析改为同步缓存层，是独立重构；本轮先落 strict + 重放，把静默错误变响。

- **HITL resume 段的模型漂移（同日追加）**：`exec_hitl_resume` 重建 Agent 时不传 model_id，`get_llm(None)` 静默落平台默认且绕过 strict 校验（None 不校验）——第一段 glm、批准续跑段 kilo 的实测漂移。修复=run 冻结模型（launch_payload.resolved_model）随 resume 链传递并重设快照；压缩摘要器（`_compaction_deps`）同族修复=未单独配置时沿用本 run 模型。

## 后果与代价

- 配置失效（Provider 删除、模型条目清理、数据迁移遗漏）从「静默换模型」变为「run 失败并报模型不存在」——用户必须修配置才能继续，这是裁决要显性化的代价。
- followup 按轮覆盖到**另一个自定义模型**时（跨线程场景）当前会报错而非路由——覆盖快照需要沿 executor 传解析结果，已知限制，出现需求时在 executor 侧补快照透传。
- 回归资产：`tests/test_qa_model_resolution_contract.py`（strict 三连 + 内置 id 正常路径）、`tests/test_runtime_model_snapshot_replay.py`（跨线程/跨 loop 重放、id 不一致不重放）。
